# Study materials

This directory is reserved for the frozen materials associated with the confirmatory study registered in Protocol v1.3.

The canonical pre-registration is archived at:

- https://doi.org/10.5281/zenodo.22245523

Under the registered procedure, exact model identifiers and provider defaults, the randomisation schedule (or its SHA-256 hash), analysis script, coding manual, hedge lexicon, and specificity anchors are frozen in a dated collection-start amendment **before any confirmatory conversation is run**.

Materials should be added here only after they have been frozen/deposited according to that protocol. This GitHub directory is a convenience mirror and does not supersede the timestamped Zenodo record.
