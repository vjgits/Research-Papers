# V8.6 — Typed Relation Attribution and NLI Validation (Frozen Before Run)

## Goal
Test the observed V8.5 error, where a verified quote said *Kalank was directed by Abhishek Varman and produced by Karan Johar* but a `directed_by` edge was incorrectly attributed to Karan Johar. Determine (a) whether typed-clause scoping and pretrained three-way natural-language inference can distinguish entailment, neutrality and contradiction on explicit author-constructed controls; and (b) whether **filtering**, rather than rewarding all keyword-cue edges, improves retrieval within a **fixed CE96 candidate pool and identical pretrained CE relevance scores**.

## Locked methods and labels
- Original BM25 and **unchanged V7.1 indexed graph**.
- Original **CE96** (two original V7.1 anchors protected).
- **V8.5 sourced CE96** +0.08 bonus for any observed directional cue with exact source offset.
- **V8.6 typed CE96** +0.08 only if a relation cue is in the *same local clause as the target*, with matching predicate and no explicit negation/uncertainty.
- **V8.6 typed+NLI CE96** same pool, CE scores and first-two anchors; +0.08 only if typed clause passes AND a pinned `cross-encoder/nli-MiniLM2-L6-H768` classifies the hypothesis as entailment with **softmax P(entailment) >= 0.70** and margin >= 0.10 over both other classes. Label order: 0 contradiction, 1 entailment, 2 neutral. HF pinned revision `9aa22b250d25a10ac39ab4a6b2bc28213507cb0c`. Max 32 candidate source edges per query. Fixed CE model `cross-encoder/ms-marco-MiniLM-L6-v2` CPU 2 threads, max 192 tokens; dense model `sentence-transformers/all-MiniLM-L6-v2`. Model CE/dense revisions are not pinned; disclose this limitation. Standard pretrained models, no fine-tuning.

NLI verified entailment is **not** truth of a source, and a single local clause can be wrong, ironic, quoted or outdated. Test *source-to-claim textual support*, not epistemic certainty or final answer generation.

## Pre-registered datasets and expected limitations
- Frozen deterministic **272 authored contrastive examples** generated by `create_fixture.py` and hashed in results: 54 author-template examples per relation family (five relation families x 6 entity sets x 9 patterns = 270), plus two known Kalank producer/director cases = 272. Balanced 91 entailed / 90 contradicted / 91 neutral. Cases are *author-generated controls*, **not independently human-verified real-world labels**. Report three-way confusion, entailment precision/recall/F1, and the specific Kalank cases. No threshold tuning on these samples.
- Public 2Wiki validation: original deterministic eligible sorted positions **1681–1800** (120 questions). Public MuSiQue validation: positions **1121–1280** (160 questions). All question IDs disjoint from previous experiments; dataset families reused iteratively and pooled question-provided support/distractors. **NOT sealed independent**, and gold sources included by construction.
- No 5+/8-hop real question evaluation. Supporting-source count is not necessarily logical step count. No answer generator, fact-check truth adjudication, contradiction resolution, calibrated abstention, official IRCoT/HippoRAG2 baseline, or claim of state-of-the-art performance.
- All gold IDs are read only *after* every method ranks sources. Same CE96 pool/scores across CE96, sourced, typed, typed+NLI. Only typed+NLI adds NLI model inference. Report per-question full-chain@5/@10, 2/3/4-support strata, 5000-draw paired bootstrap CIs, wins/losses, full wide192 and shortlist96 gold coverage, positive verified edge counts, provenance exact quotes, and CPU model init/index/inference separately. No paid API, no agent reviewer, no schedules. Keep main untouched.

## Decision gate
A challenge-set improvement does not justify promoting the new method. Only if final chain@5 improves over V8.5 sourced with paired uncertainty and acceptable additional CPU cost should we pursue an **independent sealed** relation grounding followup; otherwise report negative and return to the full-chain candidate ranking bottleneck. This version makes no claim of solving MuSiQue 4-source cases until measured.
