# PGER V9.7–9.9 frozen-stage protocol and prior-work boundaries

**Locked at commit 01dd4ec, before results were accepted.** Original V9.7 run 40712378261 was cancelled because the initial V9.8 routing feature used dense retrieval to decide whether to call dense retrieval, invalidating its cheap-first premise. The corrected run uses only question length, question-term overlap of V7.1 results, BM25/V7.1 rank overlap, and preindexed title-graph counts. No expensive model outputs enter the gate. This is an engineering/methodology fix before interpreting confirmation, not a tuned score.

V9.7: Compare unchanged V7.1, two extra BM25 searches, pretrained open-weight BGE-small-en-v1.5 direct dense retrieval, and fixed dense/V7.1 rank fusion. Only use published SAG2 original source corpus, 2Wiki and MuSiQue, questions 0..119 development and 120..239 confirmation. Record exact model/weight revision, MIT license, CPU model-loading/index/encoding costs; report source candidate coverage separately from Top5 chain assembly and actual answer correctness. **Dense indexing cost invalidates any zero-ingestion-efficiency claim.**

V9.8: Only after development observations are complete, compare direct fast vs dense fusion. Use logistic benefit predictor trained exclusively on win/loss cases with independent online features (never dataset identity or gold support), fixed C=1, predicted benefit gate 0.60; disable if fewer than two positive dense gains or positives do not outnumber losses. Freeze for distinct 120-question public confirmation cohorts. The experiment precomputes all dense embeddings for evaluation, so observed routed fraction only supports a *counterfactual compute budget*, not a measured production speedup. Do not claim true cheap-first latency without an online serving benchmark.

V9.9: Train a separate regularized logistic model to estimate **annotated passage-chain retrieval@5 success**, not truth of a generated answer, on 240 development cases and report Brier versus a constant-prevalence control, five-bin calibration error, AUC and precision at 40/60/80/100% coverage on 240 confirmation cases. No literal abstention system exists without answer generation or independent semantic verification.

Originality: Dense retrieval and adaptive query routing are established prior art. Multi-hop gap policies and typed verification were already studied by S2G-RAG, AdaKG-RAG and GroundRAG; source repair/pruning appears in SPARE-RAG. Claim no novelty or general SOTA. Every unsuccessful arm and all per-question traces must be archived. No paid APIs, recurring scans, auto-merges or main changes.

Caveat: the full 1,000-question SAG2 public test corpus has been studied in previous PGER V7.1 runs; confirmation IDs are question-disjoint from each current developmental cohort, but cannot be called sealed independent generalization.
